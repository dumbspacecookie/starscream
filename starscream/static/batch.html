Batch upload

Validate and upload many contribution packages at once — via CLI or ZIP upload.

CLI workflow

Each package is a directory with manifest.json and its paired raw audio file. Use the starscream-contrib tool from your terminal:

# Scan a tree of packages and validate all manifests + audio starscream-contrib validate-batch ./my-recordings/ # Upload all valid packages to the API starscream-contrib upload-batch ./my-recordings/ --api http://localhost:8000 # Optional: write a JSON report after upload starscream-contrib upload-batch ./my-recordings/ --report batch-report.json

New to contributions? Run starscream-contrib init ./clip-name to scaffold a manifest. See CONTRIBUTING.md for full guidelines.

ZIP upload (optional)

Upload a ZIP archive of contribution packages to POST /v1/contrib/upload-batch. Requires your contributor API key (register here).
