# Starscream v0.1 scope

v0.1 is a **narrow, provable core** — not the full platform surface. Everything outside this list ships as experimental preview code.

**Primary product:** acoustic **catalog** (metadata + upstream links), not audio hosting. See [REDISTRIBUTION.md](./REDISTRIBUTION.md). Default `CATALOG_ONLY=true`.

**Consumer surfaces (no Docker):** `starscream-catalog` CLI, `starscream-mcp`, `corpus/dataset.jsonl` — see [CATALOG.md](./CATALOG.md).

## v0.1 core (supported)

| Capability | Path |
|------------|------|
| Contribute audio + manifest | `POST /v1/contrib/upload`, web UI `/upload` |
| Validate before upload | `POST /v1/contrib/validate` |
| Store FLAC/MP3 + spectrogram | MinIO via `starscream.storage` |
| Fingerprint + dedup | `starscream.pipeline.fingerprint`, `dedup` |
| Metadata enrichment (optional) | geocode / habitat / weather — disable via env for tests |
| Full-text search | `GET /v1/search` via Meilisearch |
| Spatial browse | `GET /v1/recordings?near=lat,lng&radius_km=` |
| Recording detail | `GET /v1/recordings/{id}` |
| JSONL export | `starscream-export run --format jsonl` (requires `[export]` extra) |
| Health + dependency checks | `GET /health` |
| Seed data | taxonomy, sources, bucket, search index |

**Proof target:** one recording flows upload → Postgres+PostGIS → S3 → Meilisearch → search.  
See `tests/test_e2e.py` (requires Docker).

## Experimental (present but not v0.1 promises)

| Feature | Notes |
|---------|-------|
| GraphQL (`/v1/graphql`) | Requires `[graphql]` extra; not in default Docker image |
| ML classifiers (`[ml]` extra) | TensorFlow; Python 3.11–3.12 only — see support matrix |
| BitTorrent export | `starscream-export torrent` |
| Hugging Face publish | `starscream-export publish` |
| MQTT sensor ingest | Handler + `python -m starscream.sensor.mqtt_subscriber` (needs broker); HTTP fallback: `POST /v1/sensor/ingest` |
| WebSocket live stream | `/v1/stream/ingest` |
| Peer review / leaderboards | Requires contributor API key; admin key also accepted |
| Federation harvest | Freesound, Xeno-canto, iNaturalist, Internet Archive (live APIs) |
| NOAA / NASA connectors | **Seed catalogs** (~40 curated files), not live federation |
| Regional S3 mirrors | `MIRROR_ENDPOINTS` |
| Scheduled harvest daemon | `python -m starscream.jobs.scheduler` |
| Admin API | Requires `ADMIN_API_KEY` |

## Python / Docker support matrix

| Install target | Python | Extras |
|----------------|--------|--------|
| Local dev (recommended) | 3.11 or 3.12 | `.[dev]` |
| Docker prod image | 3.11 (slim) | base package only |
| ML classifiers | 3.11–3.12 | `.[ml]` — TensorFlow has no 3.13+ wheels |
| Parquet / HF export | 3.11+ | `.[export]` |
| GraphQL | 3.11+ | `.[graphql]` |

## Explicitly out of scope for v0.1

Until [ROADMAP.md](./ROADMAP.md) Tier 0 is complete, **do not expand** the platform with:

- New federation connectors or static importers (v0.2)
- Celery/RQ, multi-region HA, second primary database
- AudioSet YouTube download at scale
- GraphQL / BitTorrent / MQTT as *supported* surfaces (remain experimental)
- ONNX / ML pipeline in default Docker image

v0.1 ships when: clean git tree, green integration CI, one validated corpus export.

## What “release-ready” means for v0.1

1. E2E test passes against real Postgres+PostGIS, Meilisearch, MinIO
2. Upload does not block the async event loop
3. `docker compose -f docker-compose.prod.yml up` runs migrations + seed automatically
4. LICENSE (code) + data license documented
5. CI runs ruff + unit tests; integration job runs E2E when Docker is available
6. Untracked core committed; corpus proof per [PHASE2_RUNBOOK.md](./PHASE2_RUNBOOK.md)
